Experiment No. 9 Basic Dashboards in Tableau

Aim: To create basic dashboards in Tableau by combining multiple visualizations.

Description: A dashboard is a collection of multiple visualizations presented in a single screen. Dashboards help users compare different aspects of a dataset and understand overall performance quickly.

Uses: • Combining multiple charts in one view. • Monitoring key performance indicators. • Comparing categories and regions. • Supporting interactive analysis. • Presenting information to decision makers.

Algorithm:

Open Tableau Public.
Connect to the dataset.
Create multiple worksheets.
Open the Dashboard tab.
Drag sheets into the dashboard.
Add filters and interactive elements.
Arrange the layout properly.
Save the dashboard.
Sample CSV File:

City,Region,Sales,Quantity Hyderabad,South,55000,2 Delhi,North,20000,3 Mumbai,West,30000,4 Chennai,South,25000,2 Kolkata,East,15000,5 Bangalore,South,40000,3

Result: Thus, a basic dashboard was successfully created in Tableau using multiple visualizations.
